# 音声付きの競技説明（2026-11-28、v0.22.0、M01 で試し）

## 仕組み（全競技で共通）

- 声と字幕：`src/data/tutorial_voice.json`（競技 ID → 段階 ID → 音源と台本）。音源は `public/assets/audio/voice/gm/<競技>/`、無加工。大きさは `scripts/level-voices.py` で他の声と同じに揃える。
- 段階の図と操作：`src/ui/voiceguides.ts` の `VOICED`。動かす所は `src/ui/voicetut.ts`。
- 新しい競技を足す時は、上の 2 つに足すだけ。声が無い競技は、今までの説明（`tutorial.ts`）のまま。
- ゲームマスターの胸から上（`characters/host_observer/portrait_normal.png`、表示の範囲だけ絞る）。字幕は声の進みに合わせて少しずつ出す。声の間は BGM を 3 割に下げる。声は重ねない。
- 聞き直す、声を止める／再生、戻る、次へ。操作の段階は、操作が済み声も終わると自動で次へ。閉じると声を止める。開いている間は大会の時計と競技の時間を止める。
- 初めての時は説明全体を飛ばせない（1 段階ずつの「次へ」はできる）。2 回目からは「説明を飛ばす」が出る（見たかどうかは端末に記録。新しく始め直しても残る）。
- 試合中の「ルール」から、いつでも同じ説明を見直せる（閉じるボタンあり、時間は止まる）。

## 2026-11-28 の改め（v0.23.0、本人の指示）

- 初めての時も、説明全体を飛ばせる。手帳の「ルール」から、今日と前の日の競技の説明をいつでも見直せる（音声付きは声つき）。
- 収録に無い決まり（ステージの間の 20 秒の休憩、3 ステージ後の組替え、枠が大きくなること）は、「休憩と組替え」の段階で、字幕と図だけで説明する（声は鳴らさない）。
- 声を部品で使い回せる形にした（`src/data/tutorial_voice.json`）。
  - 収録ごとに、合う場面を `fits` に書く（M01 の名前の声は「第 1 競技」、組の声は「3 組、4 人、6 ステージ、120 秒」）。
  - 場面（第何競技か、決勝か、参加する人数）が合わない時は、その収録を使わず、部品の声を順に鳴らし、字幕は場面に合わせて作る。
  - 部品：`slots.order`（「第N競技」「決勝」。キーは番号か final）、`slots.stages`、各競技の `slots.name`（競技名だけ）。いまは未収録なので、合わない時は字幕だけになる。
  - 組の図は、その場の参加者から作る（人数や顔ぶれが変わっても合う）。
- 他の競技への展開は保留（iPhone で試したあと、録り直しの声で作る）。
