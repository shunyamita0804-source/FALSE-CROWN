# グラフィックの方向性

2026-11-27 時点でのユーザー指示をまとめたものです。実装はこの方針に従います。

## 参考にする範囲

GBA の見下ろし型 2D ゲームを参考にするのは、**フィールド上のキャラクターについて次の 4 点のみ**です。

- 頭身
- シルエット
- 見下ろし視点
- 移動方式

ゲーム全体を GBA 時代の低解像度・レトロ調にする意図は**ありません**。

## 方針

- タイトル、UI、文字、会話、頭脳ゲーム画面は現代的な高解像度描画とする
- フィールドも高精細な 2D グラフィックを採用する
- フィールド描画と UI 描画を分離する
- 全画面へのピクセル化、ぼかし、レトロフィルターは禁止
- 光源、影、質感、画面遷移なども作り込む
- スマートフォン向け商用ゲームとして通用する品質を目指す
- 低解像度の描画方式を正式仕様として固定しない

## 基盤での対応

- キャンバスは端末の実解像度（CSS ピクセル × devicePixelRatio）で描画する。低解像度で描いて拡大する処理は入れない（`src/display/viewport.ts`）
- アンチエイリアス有効。`pixelArt` 設定や CSS の `image-rendering: pixelated` は使わない
- フィールド（`src/scenes/FieldScene.ts`）と UI（`src/scenes/UIScene.ts`）は別シーン・別カメラで重ねて描画する
- レイアウトは高さ 1080 を基準にした論理座標で行い、横幅は端末の縦横比に合わせて伸縮する（数値は仮。`src/config/display.ts`）

素材の解像度、キャラクターの寸法、演出の具体的な仕様は未確定で、提供される仕様・素材に合わせて決めます。
