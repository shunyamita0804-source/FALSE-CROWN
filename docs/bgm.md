# BGM の差し替え手順

BGM は「場面」と「音源ファイル」の対応表だけで管理している。プログラムは場面の名前（`title`、`living` など）で再生を指示するため、曲を替えるときにプログラムを書き換える必要はない。現在入っている曲は仮の割り当てで、ユーザーが選定した音源に置き換える予定。

## 手順

1. 新しい音源を `public/assets/audio/bgm/` に置く。形式は m4a（AAC）を推奨する。iPhone の Safari でも再生できる。mp3 でもよい。
2. `src/data/bgm.json` の該当する場面の `file`（ファイル名）、`title`（曲名。クレジット画面に出る）、`by`（配布元。`credits` にある名前）を書き換える。
3. 新しい配布元の場合は、同じファイルの `credits` に名前、URL、ライセンス表記を足し、リポジトリ直下の `CREDITS.md` にも書く。
4. 使わなくなった古い音源は `public/assets/audio/bgm/` から削除する。
5. `npm run build` で確認し、main へ反映する。

## 場面の一覧

| 場面の名前 | 流れる場所 |
|---|---|
| `title` | タイトル画面 |
| `opening` | 開会式・大会説明（説明の声の間は自動で音量を下げ、説明の終わりにフェードアウト） |
| `introduction` | 参加者の自己紹介（暫定でラウンジ曲） |
| `corridor` | 生活棟の廊下 |
| `room` | 個室 |
| `living` | 生活棟のその他の部屋（図書室など） |
| `common` | 共用施設、食堂、1 階 |
| `lounge` | ラウンジ |
| `prison` | 監獄棟 |
| `hidden` | 隠し部屋、裏ゲーム |
| `match_main` | 競技説明、作戦時間、メインマッチ |
| `match_prison` | 監獄マッチ |
| `final` | 決勝戦 |
| `elimination` | 脱落、敗退の結末 |
| `ending` | エンディング |

## 各項目の意味

- `file`：ファイル名。空文字（`""`）にすると、その場面は無音になる。複数の場面に同じファイルを指定してもよい。
- `title`：曲名。クレジット画面に表示する。
- `loop`：`true` で繰り返し再生する。
- `xfade`：ループ用に作られていない曲で、末尾と先頭を短く重ねてつなぐ指定。ループ用の音源なら不要。
- `label`：管理用の説明。ゲームには表示しない。
- `gain`、`lufs`：曲の大きさを揃えるための再生時の倍率と、測った大きさ。曲を差し替えたら `python3 -I scripts/level-bgm.py` を実行すると書き直される（全曲を -23 LUFS、声より 4 LU 小さくに揃える）。

## 場面を増やすとき

場面を細かく分けたい場合（例：朝と夜で曲を変える、競技ごとに曲を変える）は、`src/audio/audio.ts` の `BgmId` に名前を足し、`src/app/game.ts` の `fieldBgm` などで場面を選ぶ条件を足す。
