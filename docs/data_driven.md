# 人数や数を決め打ちしている所の点検（2026-11-28、v0.23.0）

2 周目以降に NPC や競技を入れ替える予定のため、決まった人数、日数、並びに頼っている所を調べた。

## 今回直した所

| 所 | 前 | いま |
|---|---|---|
| 決勝の日（`isFinalDay`、1 日の予定） | 競技 ID が m11、または DAY 11 で決め打ち | 日程（`CONFIG.schedule`）の最後の日（`FINAL_DAY`） |
| 開会式の人数と日数（文と図） | 「12 人」「11 日間」「上位 8 人、下位 4 人」を直書き | 日程から数えて差し込む |
| M01 の音声付き説明の組の図 | 名簿の先頭から 4 人ずつ 3 組 | その場の参加者を、競技と同じ決まりで組分け |
| 説明の声 | 「第 1 競技」「3 組」の収録を常に使う | 場面が合う時だけ使い、合わない時は部品の声と字幕（`docs/voice_tutorial.md`） |
| 手帳の「ルール」 | 今日の競技だけ | 今日と前の日の競技、説明を見直すボタンつき |

## もともとデータから引いている所

- 競技の並び：日程の表（`src/data/config.ts`）。競技は ID で引く。
- 声：人物ごとの表（`voice.json`）と出来事ごとの表（`announcer.json`）。音源が無い人や出来事は無音で、他は動く。
- 部屋、調べる地点、NPC のたまり場：部屋ごとの表（`src/world/maps.ts`）。
- 裏ルートの日の条件：表（`HIDDEN_MIN_DAY`、手がかりの `fromDay`）。

## 入れ替えの前に直す必要がある所（今回は直していない）

- 名簿（`ALL_IDS`、`src/data/characters.ts`）が固定。セーブの人物、生活棟の個室 301〜312 の割り当て、関係の初期値がここから作られる。入れ替えるには、名簿をセーブに持たせる必要がある。
- 開会式の受け答えは、決まった NPC（朝比奈、御堂、桐生、如月など）が話す。入れ替える時は、話す人をその回の名簿から選ぶ形にする。
- 裏ゲーム H07 と手紙 L01 の文の「12 人」は、物語の中の過去の数なのでそのままにした。
- 各競技の最大人数（例：M01 は 12 人）はルールの一部なので変えていない。
