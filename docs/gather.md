# 競技会場への集合移動（v0.29.5、2026-11-28 本人の依頼）

競技の前に、全員が今いる場所から実際に歩いて会場へ向かう演出。コードは `src/core/gather.ts`（動き）、`src/core/gathertalk.ts` と `src/data/gather_talk.json`（集合中の会話）、`src/ui/gather.ts`（画面）、`src/app/game.ts` の `gather`／`gatherPrison` フェーズ。

## 流れ
1. 自由時間の締切（12:00／18:00）で「集合案内」を出す。案内を閉じるまで集合期限は数えない
2. 集合移動中：時計は 12:00／18:00 で止まったまま。競技の制限時間も始まらない
3. 全員が会場に着く（主人公が会場に入り、NPC 全員が席に着いてから約 1 秒）か、集合期限、または「会場へ移動」で終わる
4. メインマッチはルール説明 → 作戦時間（M01 の試作。競技用の相談コマンド）→ 競技。監獄マッチはルール説明 → 競技

## NPC の動き
- 食事・会話・休憩を切り上げ、今いる場所から各自で会場へ歩く。歩き出すまでの間（0.3〜3.2 秒、座っている人・話している人は +2.6 秒、野心の強い人ほど早い）と歩く速さ（0.88〜1.10 倍）が人ごとに違うので、一列にはならず廊下や中央ホールで自然に合流する
- 主人公と同行中だった仲間（自由時間の締切の直前に同行していた人）は、主人公の後ろについて行く
- 会場に入った人は、入口で止まらず参加者席（足りなければ会場の待機地点）へ進んで座る
- 監獄マッチ：監獄棟の参加者だけが会場へ向かう。生活棟の人はリビング（`dining`）へ向かう。主人公が生活棟の時、主人公は歩かない（今までどおり速報の画面へ。速報の作り直しは別の作業）
- 集合中は NPC 同士の交渉・噂・密談は起きない（自由時間の思考 `tickNpcs` を回さない）

## 救済（遅刻で失格にはしない）
- 部屋の経路が無い人（閉じ込め・つなぎ替え）：すぐ会場の席へ移す
- 同じマスで 5 秒動けない人：主人公から見えていなければ会場の席へ移す。見えていれば近くの空いたマスへずらして歩き直し、14 秒たっても動けなければ移す
- 集合期限（案内を閉じてから 90 秒）：会話を安全に閉じ、まだ着いていない人を会場の席へ移す
- 「会場へ移動」（上の帯）：確認の後、移動を省いて全員を席へ移す（主人公が道に迷った時もこれで進める）
- 救済で移した回数は `GatherState.rescued` に残す（試験で 1 回以下を確かめている）

## 主人公の操作
- 会場への最短の道にある扉だけ通れる。寄り道の扉、調べる所、椅子は「今は集合が先だ。会場へ向かおう」と短く出す（同じ案内は 2.6 秒の間は重ねない）。会場に着いた後は「もうすぐ始まる。会場で待とう」
- 移動の入力は止めない（案内はトーストだけ）
- 上の帯：目的地、次に通る扉（「次：1F 中央ホール（下の出入口）」）、到着人数、集合期限、「会場へ移動」。フィールドの次の扉に「会場へ」の矢印
- 手帳・アイテム・設定は使える（開いている間は全員が止まる）

## 集合中の会話
- NPC に話しかけると、通常の会話メニューではなく人物らしい一言だけ（閉じるボタンは「会場へ向かう」）。話している間は相手が立ち止まり、閉じるとすぐ歩き出す
- 一言の選び方（`gatherMood`）：警戒・敵意が強い → 素っ気ない一言、緩い約束がある → 「さっきの約束、覚えているよ。協力できる勝負なら、一緒にやろう」、親しい（好意 60 以上）→ 親しい一言、監獄マッチ → 崖っぷちの一言、前の競技の公開順位が上位／下位 1/3 → 結果を気にする一言、それ以外は性格（大胆さ・野心・慎重さ・探索好き・観察力）で「自信／緊張／観察／冗談」
- ルール未公開なので、作戦・秘密・ルールの中身は話さない（台詞に「作戦・秘密・攻略・正解・ヒント」が無いことを試験で確かめている）
- 関係の値は動かさない。同じ相手に 2 度目以降は「続きは会場で」の短い返事だけ（繰り返して親密度を上げられない）

## 暫定の値（実機で調整）
`GATHER`（`src/core/gather.ts`）：集合期限 90 秒、歩き出しの間、速さの幅、詰まりの判定 5 秒／14 秒、そろってからの間 1.2 秒。一番遠い個室から会場まで、NPC は約 50 秒で着く（`scripts/check-gather.cjs`）。

## 確認
- `tests/gather.test.ts`：全部屋から会場への道、散らばった NPC が救済なしで期限内に席へ着く、歩き出しと速さのばらつき、寄り道の禁止、監獄マッチの分かれ方、期限での安全な移動、閉じ込めの救済、会話で関係が動かない・2 度目は短い・約束に触れる、台詞に作戦の言葉が無い
- `scripts/check-gather.cjs`：集合案内 → 集合移動中 → 寄り道の案内 → 一言の会話 → 全員到着 → ルール説明（スマホ横画面）
