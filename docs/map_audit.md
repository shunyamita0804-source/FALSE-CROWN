# 館内マップの点検（2026-11-28、v0.20.2）

※ v0.26.0 の建物改修で、15 部屋の家具と当たり判定を新しくした。その内容は `docs/map_redesign.md`。

建物の絵（正式素材）は加工せず、プログラム側の当たり判定、調べる地点、NPC のたまり場だけを直した。
点検した部屋：3F〜B2 の全 32 部屋（個室と監獄棟の個室は同じ形なので代表 1 つずつ）。
点検の決まりは `tests/mapaudit.test.ts` に入れた（全部の出入口と調べる地点に歩いて行ける／NPC のたまり場は出入口から 3 マス以上離れ、出入口の正面の通り道に無い／入ってすぐの 1 マスがふさがれていない）。

## 2. 絵の直しが必要な部屋（理由と、必要な直し）

寸法はすべて、いまの絵と同じ（1 マス 64 ピクセル）。差し替えは同じ場所に同じ名前で置けば、そのまま反映される。部分だけの直しは「透過 PNG の重ね絵」（部屋の絵と同じ寸法、直す所以外は透明）でもよい。

|---|---|---|---|
| 高 | 3F 遊戯室（`maps/3f/game_room.png`、1536×1024） | 入口の真正面（横 10〜13、縦 11〜13 マス目）に丸テーブルがあり、入ってすぐ左右へ回り込む必要がある | 真ん中下の丸テーブルを外すか、上へ 2 マス以上動かし、入口から部屋の中央まで 3 マス幅の通り道を空ける |
