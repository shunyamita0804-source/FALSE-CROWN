## 仕組み：内部ID と表示名を分けた

- 内部ID（`npc_02_kanzaki` など）は改名しても変えない。素材のフォルダ（`public/assets/characters/<内部ID>/`）、音声のフォルダ（`public/assets/audio/voice/<内部ID>/`）、セーブデータ、関係値、競技の記録はすべて内部ID で持つ。
- 表示名は `src/data/npc_names.json` だけにある。`name`（姓名）、`short`（呼び名。会話、ログ、部屋の札、名簿）、`kana`（自己紹介の読み。カタカナの名前なら空でよい）。言語ごとに書け、`en` が空なら日本語を使う。主人公の名前の初期値（`hero`）もここ。
- `status` は `original`（旧名のまま）か `renamed`（差し替え済み）。
- `src/data/characters.ts` の `NPC_BY_ID[id].name / .short / .kana` は表から引く（いまの言語で）。画面のコードは今まで通りこれを使えばよい。
- データの文章に名前を書く時は、直接書かずに `{name:<内部ID>}`（姓名。日本語の文中では空白を詰める）、`{short:<内部ID>}`、`{kana:<内部ID>}` と書き、`fillNames()` を通す。手帳の資料と裏ゲーム H07 の問題（`src/story/hiddendata.ts`）、自己紹介の仮の字幕（`src/data/introductions.json`）はこの書き方に直した（表示は今までと同じ）。
- 自己紹介の声には、声の中で名乗っている名前を `spokenName` として `src/data/voice.json` に書いた。表の名前と違えば（改名して、まだ録り直していなければ）その声は鳴らさず、字幕は新しい名前で出る。
- `tests/npc_names.test.ts` が、表の抜け、置き換え漏れ、名前の直書き（コメントと、下の「直書きしてよい所」を除く）を見張る。

### 直書きしてよい所

- `src/data/voice.json`：音声の台本。字幕と声を一致させるため、録り直した音声と一緒に書き換える。
- `src/data/npc_profiles.json`、`src/data/puzzle_data.json`：仕様書 v03・v04 の写し。画面には出ない。

## 改名の手順（名前が決まったら）

1. `src/data/npc_names.json` の、その人の `ja.name`・`ja.short`・`ja.kana` を書き換え、`status` を `renamed` にする。これで名簿、会話の名札、ログ、噂、部屋の札、房の札、手帳、自己紹介の名前、開会式の名札がすべて変わる。
2. 自己紹介の声を録り直したら、`voice.json` のその人の `extra.introduction` の `text` と `spokenName` を新しい台詞と名前にする。届くまでは声なしで、字幕は `introductions.json` の文（新しい名前入り）が出る。
3. 職業や経歴も変える時は、`docs` の一覧（共有フォルダ `npc_rename/npc_text_audit.csv`）の「経歴」の付いた文を書き直す。
4. `python3 -I scripts/audit-npc-text.py <出力先>` で一覧を作り直し、`npx vitest run tests/npc_names.test.ts` を通す。

### 気をつける所

- 名前の変更は、古いセーブデータのログや噂の文には及ばない（その時の名前で文として残っている）。新しく起きた出来事から新しい名前になる。
- 絵：素材は内部ID のフォルダに置くので、新しい通常絵を同じ名前のファイルで置き換えれば差し替わる。表情、歩行、着席は通常絵の確定後（本人の方針）。
- 声に合わせるため、性別と年齢（`characters.ts` の `gender`・`age`）は声に合ったまま変えない前提。
