## つながり（通常の動線）
- 3F 生活棟：個室 12 ↔ 生活棟廊下 ↔ リビング（部屋 id は `dining` のまま。食堂の絵）。廊下の左端は図書室（寄り道、生活棟の裏ゲームの入口）
- リビング ↔ 遊戯室（右上）、シャワー・トイレ（部屋 id は `bathroom`、右の壁）、階段で 1F 中央ホール（下の中央）
- 1F：中央ホール（棟間の移動口。左の窓口が交換所）↔ 大会競技場（相談室・手続き室は会場の作業）
- B1 監獄棟：中央ホールの鉄扉 ↔ 共同牢 ↔ 監獄マッチ会場（共同牢の右上の格子門）。上の中央の隠し扉は第零牢（監獄棟の裏ゲーム）
- 立入制限（`access.ts`）は変えていない。リビングと浴室の区分を「生活棟」にしただけ

## 通常の動線から外した部屋
`src/world/maps.ts` の `RETIRED_ROOMS`。部屋の定義と絵は残す（削除しない）。どの扉からも入れず、開発者メニューで入った時は、扉から移し先へ出る（片道）。
生活棟ラウンジ、2F 共用廊下、共用ラウンジ、屋内庭園、展望室、交換所、医務室、玄関、監獄棟通路、旧書庫、地下通路、B2 の秘密の書斎と第零牢以外。

## 古いセーブ
- セーブの版を 2 に上げた。読み込む時（`src/save/save.ts` の `migrate` → `src/world/sim.ts` の `relocateStranded`）に、次を行う
  - 外した部屋にいる人は `RETIRED_ROOMS` の移し先へ（入れない時は寝起きする場所へ）
  - 外した部屋へ向かう予定・道順は取り消す
  - 自分の寝起きする場所へ歩いて帰れない所にいる人（例：生活棟の人が第零牢に残っている）は、寝起きする場所へ
- 個室の招待、手掛かり、アイテム、開けた扉、裏ゲームの記録は消さない
- 確認は `tests/layout.test.ts`（道の長さ、両棟の分かれ方、移し替え、閉じ込め）と `tests/world.test.ts`
