# チュートリアル仕様
## 原則
初回のみ導入を提示し、すべてスキップ可能。練習は任意、本番での敗北を救済しない。練習の得点・ピース・信頼・乱数状態は本編に反映しない。説明・練習は大会開始前または競技説明フェーズ内で行い、自由行動中に開く手帳は閲覧だけ可能。リアルタイムの探索・交渉中は時間が進む。ポーズ・アプリ非アクティブ時は停止し、NPCも同時停止。競技固有の計時は再開時に残時間を維持する。
## 導入
1. 移動：十字キー/タップ/PCキーで任意地点へ。2. 調査：家具を調べる。3. 会話：NPCを選び会話。4. 交渉：架空の練習相手に0〜3ピース提示、拒否や対案も体験。5. 手帳：確認済み情報と伝聞の違い。6. 大会：メイン下位→監獄マッチ→最下位脱落、ピース0は脱落しない。7. 練習競技へ任意で進む。各段階は飛ばせ、実際の大会状態を変更しない。
## 競技説明
各競技の開始前に目的、人数、終了条件、合法手、得点、公開/非公開情報、同点処理、棟分けまたは脱落条件を表示。短い要約→図解→詳細ルール→任意の練習。数値は実装側ルールを参照。練習は固定の独立状態で合法手の理由と結果を提示し、途中終了可能。練習で使用する問題・乱数は本番と別。隠し競技は発見までタイトルも説明も公開しない。
## 本番UI
行動の選択理由を強制しない。違法手を無効化し理由を表示。確定前に取り消し可、確定後は巻き戻さない。公開情報の履歴、得点内訳、自分の残資源を表示。NPC秘密情報、推奨最善手、正解の自動提示は禁止。時間切れの合法な既定行動を事前明示。選択タイマーはルールに従い、アプリ復帰で延長しない。
## セーブ
通常：複数スロットとフェーズ境界の自動保存。サバイバル：単一進行スロット、行動確定・結果確定・取引・タイマー状態を原子的に保存し再開で再抽選しない。敗北時は終局状態を保存し新規開始または結果閲覧。外部ファイル操作まで防げるとは保証しない。モード選択時に差を表示。難易度とセーブ方式は別設定。いずれも監獄最下位はゲームオーバー、決勝敗北も終局。救済なし。通常モードの手動保存可能範囲は既存仕様と整合させ、隠し情報取得後の任意巻き戻しを促さない。
## アクセシビリティ
色＋記号、文字サイズ設定、効果音とBGM個別設定、振動/点滅/演出短縮設定、タップ領域44 CSS px目安、横画面セーフエリア。ルール説明は時間制限なし。練習の時間制限は解除可能、本番は全参加者共通のルールを維持。
