# 周回・図鑑・戦績
## 保存分離
profile（永続図鑑、実績、競技解放、履歴）と run（大会進行、所持品、関係、NPC知識、乱数、時計）を分離する。新規開始時runを新規seedで初期化し、profileのみ引き継ぐ。過去周回の秘密をNPCが知っている扱いにしない。通常モードのロードでprofileの発見は取り消さないが、実績判定は現在runの正規イベント履歴に限る。既存保存はmigrationし初期値を補う。
## 解放
競技M01〜M11/P01〜P10/H01〜H08/S01〜S06は実際に本編で開始した時に解放（練習は除外）。隠し競技は発見時に図鑑へ名称のみ記録、開始時にフリー対戦解放。未発見は名称・説明・報酬・場所を伏せる。図鑑の人物プロフィールは出会い時、秘密は検証済み証拠または正規告白の取得時に解放。噂のみでは秘密解放しない。エンディングIDはv05の8種をそのまま使い終局確定で解放。敗者も対象。
## フリー対戦
解放済みゲームの独立した状態・乱数・AIを生成。通常の参加人数と合法手、難易度を維持。本編の時計・ピース・情報・関係・進行は変更不可。H系は実際に発見済みの問題のみ、S系は勝利または定義済みクリア条件で勝利扱い。対戦終了でフリー専用戦績のみ更新。本編の正解や未取得証拠を漏らさないよう探索依存問題は取得済み版または同型の独立問題を用いる。
## 履歴
終局時にrunId、難易度、モード、seed、到達日、終局種別、endingId、実際の順位と脱落順、優勝者（不明ならnull）、競技別結果を記録。同一runの同一終局は二重記録禁止。通常ロード分岐の別終局は履歴に別分岐として表示できるが、同一runの累積カウンタは各条件につき最大1回加算。未完了の大会に仮の順位や優勝者を付けない。
## 実績処理
JSONのscope=runは当該runの確定イベントのみ、profileは独立runの累積または図鑑の集合を参照。operator=gte以上、eq一致。イベントIDで重複排除。達成済みは不可逆。hiddenは達成まで名称条件を非表示。報酬は称号・記録のみ、ピースや能力補正なし。champion系は優勝確定時のみ評価。all_main_firstはM01〜M10すべて1位かつ優勝。no_allianceは正式同盟成立履歴0、no_prisonは監獄配属0、zero_piecesは決勝終了時0。kept_four_no_breachは異なる約束4件以上履行かつ自発的破約0。distinct_trusted_npcsは同一時点の信頼70以上の相手数の最大値。distinct_betrayed_partnersは確認済み自発破約の相手ID集合。unique_dealsは成立し実質対価/情報/協力を伴う一意取引、取消や同条件連打を除く。gifted_piecesは無償譲渡の純額、往復返還分除外。各hidden/subgame/secret/roomのcountは正規ID集合。profileの勝利数は独立run単位、フリー勝利数は異なる競技IDの集合。練習・デバッグ・カスタムは本編実績対象外。
## UI
タイトルから図鑑・戦績・フリー対戦へ。未解放はシルエットまたは伏字。実績通知は競技結果や自由行動の安全な境界で短く表示、入力を遮らない。終局後は結果→再挑戦/図鑑/タイトル。初回敗北でも取得済み記録を残す。
## 後回し
カスタム大会は本編の検収後。参加人数変更は各競技の対応人数を満たす組合せのみ許可、別戦績。ボイスなしで全イベント進行。オンライン・ランキング・課金は追加しない。
