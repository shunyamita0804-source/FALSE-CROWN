# 検収
- 初日脱落で終局・発見済み競技解放・未発見競技非表示。
- 8エンド各ID、通常優勝と真エンドの優先順位はv05維持。
- 新規周回でピース/関係/秘密知識/時計/乱数が初期化され、図鑑維持。
- フリー対戦前後でrunのシリアライズ値が一致。練習も同様。
- 同一結果を再読み込みしても実績/履歴/カウンタを二重計上しない。通常ロード分岐で同一runの累計加算を繰り返せない。
- 全60実績について閾値直前、到達、再イベントをテスト。条件が実際の競技仕様で到達可能かシミュレーションし、到達不能なら修正を記録。
- 未取得証拠・秘密・裏ゲーム名を図鑑、通知、フリー対戦、実績説明が漏らさない。
- 旧セーブ移行、破損時の復旧、iPhone横画面、オフラインを確認。
