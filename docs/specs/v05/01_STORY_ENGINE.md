# 物語の正史と制御
舞台は閉鎖された研究施設。賞金10億円は架空の大会賞金。CROWN計画は意思決定予測研究で過去に重大事故。今回の脱落者は生存し隔離される。事故の死傷数や詳細は確定しない。主人公は研究関係者だという証拠がなく、比較対象として招待されたという設定案。オブザーバーは計画継承者であり、競技の結果を操作しない。参加者の招待理由については、関連資料と本人の動機を区別する。如月への依頼は参加者の言動を報告すること（競技の不正操作権なし）。九条は過去の参加者だが今回は異なる競技構成で、未公開解答を知らない。久世は創設者だが現在の運営権限なし。朝比奈の兄の現在の安否は未確定とし、今回の隔離区画で必ず再会させない。
## イベント実行
JSONのphase: intro, morning, post_main, post_prison, inspect, final, ending。mandatory=trueは時計停止、任意イベントは自由時間内に実行。必須の日次イベントは短くし、長い調査は任意。スキップは演出のみで、フラグや報酬の処理は一度だけ。各イベントIDを保存、再開時は台詞位置と選択を復元。選択とフラグは原子的に保存。人物を台詞に使う場合はactiveかつ同じアクセス可能区域にいることを確認。条件不成立ならそのシーンを省略し、代替資料はv04通り。脱落NPCは隔離シーンのみ登場可能。動的変数{player},{eliminated},{winner},{opponent}は実際の結果で置換。プレイヤー脱落なら通常日程を停止。情報を読んだだけで正解フラグを与えない。プレイヤーが未取得の証拠を強制台詞で明かさない。inspectイベントは対応したv04の調査または取得時にのみ表示し、追加の解錠条件にしない。
## エンド判定
脱落は敗者エンド（決勝含む）。明示的な脱出・救出・告発は競技外でのみ実行、確認ダイアログ必須。脱出はH08成功・RELEASE_AUTH後、保守出口を開ける選択（新規案）。告発は同条件＋DOC_CROWN＋CORE01＋ISOLATION_CONFIRMEDを所持。救済は同条件＋RESCUE_READY、決行時は隔離者全員の解放を演出。真エンドは優勝＋H08成功＋RESCUE_READY。通常優勝系は、自発的に破り相手に確認された約束の固有IDが4以上なら孤独な王、そうでなく履行した約束が4以上かつ異なる3人以上から最終的に信頼70以上なら信頼の証、それ以外は王者。脱落済NPCとの関係は脱落時の最終値を保存して利用。信頼の証と孤独な王が重なる場合は孤独な王を優先。すべて暫定値。単独エンドの実行後は大会を再開しない。決勝前の救出準備だけでは退場者を解放しない。決勝後の真エンドは他の優勝系より優先。エンディング後は図鑑・フリー対戦へ。
