# FALSE CROWN Audio v07
BGM 7曲とKenney効果音を収録。仮割当はmanifest参照。タイトル専用、共用施設専用、裏ゲーム専用は未受領。暫定曲で代用可。
BGMはiOS互換を考慮し元のM4Aを無変換で採用。SEは元OGGを収録し、実機で非対応ならAACまたはWAVへ変換すること。
BGM/SE音量個別設定、ミュート、初回ユーザー操作後再生、画面移行時フェード、アプリ中断時停止、再開時復帰、重複再生防止。B04はループ版未受領なので継ぎ目確認。B11は一回再生。足音は歩行時のみ、カード操作は確定時のみ、ピースは実際の取引時のみ鳴らす。UI click/select/confirmation/back/error、casino card-place/card-shuffle/chip-lay、RPG footstep/doorOpen/doorClose/bookFlip/metalLatch/handleCoins を候補に使用。音の選定は未試聴のため実機で確認。未収録の心音・警報・勝利演出等は後日追加。クレジットを設定画面とリポジトリに掲載し、素材をコードのライセンス対象から除外。
