# 実装・UI・検収指示
## 優先不具合（v0.2.0試遊報告）
- フィールドの背景/家具/NPCタップで自動移動する処理、クリック移動パス、イベントの入力貫通を撤去。タッチは方向キーのみ、PCはキーボード併用。調べる/話すは範囲内のみ。指を離す/キャンセル/画面遷移/アプリ中断で入力を解放。NPCの自律移動・同行は残す。
- NPC速度を現在の60〜70%から調整、停止・着席・会話・食事・休憩・練習の滞在を増やす。移動は目的地に着いてから次の行動、会話中は予約・停止。招待同行で主人公速度に追従。実機で追いつけることを確認。歩行修正済み15素材を使用、待機時オフセットの差を確認。時間単位で行動、FPS依存禁止。
- 会話メニューはv10の大分類6項目、サブメニューを開いたら旧ボタンを非表示/無効化。モーダル1枚、最前面のみ入力。戻るで親へ、確定で完了、キャンセルで支払なし。タイマー切れで安全に閉じる。文字列・フォーカス・スクロールのはみ出しを検査。
- iPhone横画面のセーフエリア、ホームバー、左右ノッチを除外。ボタン44pt以上目標、押下・選択・無効状態を区別。文字サイズは実機で読めること。盤面はスクロール不要、必要なら拡大操作とタップ代替。色だけで識別しない。
## 競技UI
ルール一括長文は廃止。導入1画面→基本操作1〜3画面（盤面実演、アニメ、短文）→得点/終了条件1画面→実際に操作する練習1問→本番。スキップ可、いつでもルール再表示（競技タイマーは停止しない通常のヘルプ、初回説明は停止）。練習データと本番は別。盤面中央を最大化、HUDは順位/残時間/個人点/ラウンド、他者順位は小さな一覧または開閉。操作対象をハイライト、合法手のみ、音とアニメでフィードバック。結果は図/点数/順位と理由、長文ログは任意。対戦中にNPC会話が盤面を遮らない（サイドパネル、非自分ターンに限定）。不要な交渉はスキップ。
## 共同生活
v10を実装。朝夕の食事、入浴、就寝をNPCの日課にする。主人公は任意参加。食事時の席/会話相手は好感・目的・空きで決定、毎日固定しない。観察可能な同行や個室訪問、目撃/噂、雑談、次の競技の適法ヒント、練習、情報購入、救済約束を実装。監獄棟は18時まで立入制限、そこで少人数の交流・独自探索。22時強制帰室、翌朝へ。競技以外は探偵物語に寄せない。タイトルShiny Tech/廊下Airport Loungeを維持、個室専用曲は未決定。NPCの台詞や生活行動を心理戦だけで埋めない。
## アセット
既存の正式UI全点/建物/キャラを再利用。旧競技素材は保管し、不要なものを無理に表示しない。盤面、数字、記号、カード、ポリオミノ、グラフ、国旗はCanvas/SVG等で精密描画可能、必要に応じ既存枠に合わせる。国旗は出典と商用利用可否を確認し、出題データにライセンス記録。独自のカード・駒・問題を制作、他番組の名称・盤面デザイン・問題そのものは複製しない。追加画像が必須ならID、寸法、透過、用途、参照、優先度の一覧を提出。未制作を完成扱いしない。先にプログラム描画で操作性を検証。
## 移行
M01〜M11/P01〜P10/H01〜H08/S01〜S06のIDは維持、名称・ルール・アダプター・チュートリアル・図鑑・実績・テスト・情報販売・台詞・アセット対応を同時更新。H系の鍵/証拠/報酬フラグ維持。旧競技進行中のセーブは互換性なしとして事前警告し安全な競技開始時点へ戻す（競技開始スナップショットがある場合のみ、支払い重複なし）。なければ旧runをバックアップし新規runを案内、無断削除禁止。既存プロフィールの実績・図鑑は旧記録を区別して保存。新版の競技解放は新版開始時。購入解放や言語基盤は維持。
## 検収
1. 全35IDの実行可能な競技、全参加人数、合法手、得点、終了条件、タイムアウト、同点境界、順位全員確定、主人公脱落をテスト。決勝5種は内訳で35種に加算しない。
2. 問題生成器の可解性/正答検証/別解/難度、同一条件、同時入力、乱数再現性。少なくとも各競技100シードのCPU試合、対称盤面は席順回転も検査。優勝率、席順/チーム別差、行動頻度、同点率、時間分布、ピース有無、同盟有無、AI難易度を記録。完全なバランスを保証せず偏りを調整。CPUが隠し状態にアクセスしない負のテスト。
3. メダル: DAY1〜9各日、本人使用/放棄/辞退/交換/主人公強制移送/NPC同士/約束違反/二重使用/ロード/境界同点/DAY10・11無効、人数維持、報酬不変。救済者が監獄へ落ちない。監獄最下位だけ脱落。情報購入/使用の残高・上限・重複検査。
4. 共同生活: 時刻停止復帰、競技強制移動、22時帰還、食事任意、監獄制限、会話中締切、NPCが追いつける速度、同行・秘密・噂、普通の雑談、関係画面の秘匿。0ピース・全拒否・全勝でも真相代替経路を維持。通常優勝で満足できる演出。
5. 競技単体で会話/取引なしでも攻略可能か、初見で基本操作が理解できるか、操作中の読み物量、待ち時間、実際の面白さを人間が試遊評価。自動テストだけで合格にしない。目標時間を大きく超える場合は手数/問題数/CPU演出を調整。1周の想定競技時間は本戦11×15〜30分＋監獄参加最大10×8〜15分（実際は参加状況に依存）、自由時間も別途。セーブ中断可を必須にする。
