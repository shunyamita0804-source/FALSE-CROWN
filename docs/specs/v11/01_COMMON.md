# 共通ルール
## 日程
DAY1〜10の総人数/生活/監獄: 12/8/4,11/7/4,10/6/4,9/6/3,8/5/3,7/4/3,6/3/3,5/3/2,4/2/2,3/1/2。DAY11は2人の決勝のみ。監獄最下位1名脱落。主人公も例外なし。決勝敗者も敗退。M01〜M10は全生存者の個人順位を必ず確定する。チーム得点だけで同順位にしない。共通決定戦は35種に含めない。
## 救いのメダル
M01〜M09の1位本人に当日限り1枚。順位確定→順位報酬支給（救済で変更なし）→仮配属発表→任意の救済選択→確定配属。監獄予定者1名を指名、生活予定者の最下位1名と交換。対象は生存者のみ。放棄可、譲渡・蓄積・自己使用不可。DAY10は生活枠1名のため発行なし、DAY11もなし。本人の意思を尊重し救済対象は辞退可（辞退なら別対象または放棄）。交換された側に拒否権なし。救済の打診・取引は自由時間や競技間に可。事前約束は履行を強制しない。救済者・対象・交換者と公開結果をイベント化、恩義/警戒/敵対は性格・観測情報で更新。NPC同士も順位譲渡や救済の約束を提案し得るが、実際に合法手で行う。点数の直接譲渡は禁止。結果確定後に重複付与しない。監獄境界に関わる同点は救済前に解消。
## ピース
通常資産と競技内点数・コインは別。初期3、0で参加可、現金/課金交換なし。v01順位報酬を維持（仮配属上位に5/3/3/2/2/2/1/1を順番に適用）。各競技に明記した補助のみ購入可、NPCも同価格・同制限。購入は任意、消費確認と効果を表示、使用前に残高を再確認。直接得点、投票数、勝利、脱落免除の購入禁止。決勝は補助なし。競技内の限定ヒント・手札交換等は競技上の直接補助を許す今回の変更。情報交換は合法な既知情報だけ。秘密の将来問題や正解一覧を販売しない。勝者の固定化を計測し、補助あり/なしで逆転可能性を維持。
## 時刻と操作
v10の07:00起床、12:00本戦、14:00結果、18:00監獄戦、19:00生存者合流、20:00夕食、21:00入浴、22:00帰室を維持。競技中は日内時計停止。競技の時間制限のみ進む。ポーズ・バックグラウンド中は公平に全員停止。実時間目標: M 15〜30分、P 8〜15分、H 2〜8分、S 1〜5分。短い競技は複数問題・対戦構成で厚みを出し、単なる待ち時間で引き延ばさない。練習と交渉は任意スキップ可能。自由時間への戻りと保存を安全な区切りで行う。
## 交渉
競技前、明示したラウンド間、非自分ターンの待機窓でのみ会話可能。雑談/情報/取引/作戦/終了の大分類。対戦画面を見ながら短い会話、他者ターンで画面を隠さない。自分のターン到来・締切で未確定オファー終了。NPC処理は待機中にも進むが自分の入力時間を奪わない。個人同時タイムアタック中は会話なし。待機窓は15〜30秒目安、全員完了で早送り、CPUの行動を解決してから進む。秘密作戦・偽装同盟はv10の個室制約。競技で許可されたヒント共有・合法行動の約束のみ。NPCに実際の勝利/失点を強制する契約はなし。自主的なパス・弱い合法手は可。NPCは自分の生存期待・恩義・救済期待・信頼・利益を再評価し、裏切りも選ぶ。結果を見て過去手を変更しない。
## 得点/CPU
全員に同一の合法手生成・検証器、同じ問題難易度・配布規則。公開・本人情報だけのviewをCPUに渡し、正解/未来/相手手札へのアクセス禁止。記憶ゲームは表示時にNPC記憶を生成し、隠した後はその記憶だけ参照。能力値は探索幅・深さ・記憶誤差・判断時間に反映。速度得点は操作完了時間を用い、CPUには能力ベースの仮想時間を割当（処理時間ではない）。NPCの全行動は検証器で合法性を確認。全員同時なら確定後に公開。手番優位は交代・対称配布で抑える。無入力時はパス、必須なら選択なし/失点または事前明示した合法手。順位は各競技の得点→副得点→共通決定戦（同難度の図形・記憶等の短問、正答→時間）。全員順位確定まで同点者だけ再戦、連続同点は問題形式を変える。保存時に乱数・問題ID・回答時間・手番・購入履歴・取引・メダル状態を保持。
