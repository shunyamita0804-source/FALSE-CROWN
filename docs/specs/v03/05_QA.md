# 検収条件
下記はCCのテスト実装指示。現時点の成果は仕様と台詞データであり、製品実装の合格報告ではない。

## 単体・統合テスト（必須）
- 各NPC IDが既存v0.1のIDと一致。能力値6項目維持。人格値は0〜100、初期価格は整数か-1。台詞IDは重複なし、全NPCが32場面を持つ。
- 方向付き関係: A→Bの贈与・信頼変化でB→Aが無条件に同じ変化をしない。上限下限、同一イベントの二重適用防止。
- 0ピースで通常参加。負数/小数/NaN/期限切れ/脱落者との取引拒否。両者同意の原子的移転、イベント再送の二重払いなし。総資産は報酬・回収・公式購入以外で増減しない。
- 前払い後に裏切れる。後払いは未達時に支払義務なし、達成後不履行を観測すると関係更新。非合法になった約束はvoidで処理。複数契約の衝突、期限切れ、タイムアウト、セーブ復帰を試験。
- 同一条件で橘（仲間信頼>=65）に1/5/10/100ピースを提示しても故意の仲間裏切りを拒否。神崎は戦略利得<=0の危険な協力を高額でも拒否。御堂は利益の大きい合法提案で受諾率が上がる。価格の上下（信頼・危険・恩義・所持数）を境界値で検証。
- 交渉可能窓と棟移動制限。NPC同士の提案/対案/合意が実際に成立し、主人公だけに接触が偏らない。時間切れの未成立オファー破棄。手帳、ポーズ、強制説明、バックグラウンドで世界時計停止。
- 知識分離: 同じNPC観測状態、同じ乱数で秘密状態だけを変えた場合、NPCの行動候補/出力は同一（非公開状態差替えテスト）。公開後は変化可。秘密取引の非目撃者が関係更新しない。伝聞のprovenanceRoot重複を無視し、誤報訂正が可能。
- UI: 受諾前に台詞抽選で結果を決めない。拒否理由と価格対案を表示。隠し内心/真偽/秘密台詞の露出なし。脱落時台詞以降は通常会話不可。未解放の裏ゲームを案内しない。名前入力のエスケープ、横画面の長文折返しと操作領域。
- 各NPCがDAY1に脱落する等の早期脱落シナリオを個別テスト。代替資料でH07/H08へ到達可能。真エンドに意図的敗北や特定NPCの生存を必須にしない。
- 全35競技アダプターで合法手と観測範囲を維持。M11で取引・補助不可。v0.2のバランス修正を上書きしない。

## 自動対戦の目標（暫定の検査基準、合否を勝率だけで決めない）
NORMALでまず100通し（全NPCの代替主人公を含む同一ルールで、席・シードを変える）、他難易度で各20通しを目安に実測。動作が安定後に増やす。CPU時間・端末性能に応じバッチ分割。再現シードとバージョンを保存。各競技単体はv0.2の試験計画に従う。
記録項目: NPC別の提案数、対象の分布、拒否理由、対案、前払い/成功報酬、不履行、目撃/噂、購入/贈与、ピース総量・偏り、日別脱落、競技得点、棟移動、探索達成、選択の実行時間。高信頼・低信頼・高リスクの同条件比較。特定NPCがほぼ必ず優勝する、同じペアが全周回固定、誰も裏切らない、全員常に裏切る、価格が常に上限に張り付く場合は要調査。固定勝率を割り当てることで見かけ上修正しない。

## 手動シナリオ
A. 御堂へ低額→対案→受諾、後に第三者が引抜き。結果・残高・記録を確認。
B. 橘と同盟、別の仲間への故意の裏切りを高額で依頼して拒否を確認。
C. 白石の虚偽情報を買い、別証拠で反証。手帳の記録と関係更新が整合。
D. 成功報酬条件達成後に支払を拒否。相手が観測し後日価格・信頼に影響。自動没収なし。
E. 生活棟から見えない監獄での取引を後日第三者の噂で知る。現場を見ていない主人公に真偽を表示しない。
F. 期限直前の保留取引、アプリ中断/再開、競技への遷移で時計・支払を確認。
G. 真相条件前後でNPCの秘密台詞と代替証拠を確認。
