# 競技と交渉の接続
v0.2の競技ルールを優先。本書は各競技AIが交渉をどう利用するかの追加設計であり、得点・合法手・公開範囲を変更しない。アダプターの具体的なactionPredicateは既存の合法手型から生成する。許可された会話窓だけで成立させ、実行時に再検証。下記で「協力」とある場合も得点そのものを移転しない。

|ID|交渉/約束の対象|NPCの判断・人物例|
|---|---|---|
|M01|国ごとの生産/侵攻/防衛担当、領土指定、不可侵、諜報情報|神崎は資源予算、桐生は攻防、御堂は他国買収、橘は弱い仲間の得点を考慮。蓄財上限等はv0.2に従う|
|M02|入札の見送り、商品の交換、セット情報|御堂は限界価値と競争阻止、黒瀬は交換条件、九条は価格変動を評価。入札前の非公開額を読まない|
|M03|賛否の口約束、役職の自己申告|白石・如月は役職の推測と虚偽申告、黒瀬は合意条件、神崎は議案得点機会。秘密役職を不正参照しない|
|M04|路線建設、合法な通行許可・料金、輸送経路の共有|桐生は経路探索、御堂は需要、黒瀬は期限/料金、久世は代替経路。競技内資金とピースは分離|
|M05|ペア希望、協力の約束|橘は継続協力、白石は裏切りと評判の比較、黒瀬は約束を重視。v0.2の報酬・ペア制約を適用|
|M06|狙う塔の分担、特定塔への配置回避|桐生は残駒と塔価値、御堂は高価値塔の交渉、神崎は最適配分。相手の未公開配置は推測のみ|

## NPC間の具体例（固定イベントではない）
1. M01で御堂は他国参加者へ2〜5ピースを前払いし、特定領土を防衛しないよう依頼。相手は予想損失と要求価格を比較。受諾しても、直前に危険が増せば防衛へ変更することがある。観測した相手だけが信頼を更新。
2. 橘が朝比奈を支援し、朝比奈の橘への恩義が増える。後に別の参加者から引抜きを提案されても、十分な忠誠・信頼と利益を比較する。強制成功にしない。
3. 堂島が密談を目撃し主人公に伝える。主人公が内容を知らなければ、目撃できた事実（誰と誰が会った）だけを表示。具体的条件は盗み聞き/当事者の証言/証拠が必要。
4. 神崎がM08の手掛かりを購入したが、その口頭情報が虚偽の場合、候補が矛盾する。過去の確度と根拠で再評価し、矛盾だけで虚偽を確定しない。
5. NPCだけの監獄マッチも、同一のルールと知識制限の下で実行する。主人公が生活棟にいる時は試合の秘密状態や全会話をリアルタイム開示しない。
