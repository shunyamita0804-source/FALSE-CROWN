# NPC・交渉エンジン仕様
## 不変条件
12人固定、0ピースでも生存。棟分けは当日メイン順位だけ。監獄マッチ最下位だけが脱落（決勝敗者は例外）。ピースで得点・票・勝利・免除を直接購入できない。投票の約束や情報売買は可、履行は任意。NPCと主人公の行動権限・情報制約は同じ。NPCの秘密内心や真偽をUIに漏らさない。
## 状態モデル（型の例、既存名へ対応させる）
- Character: id, active, room, pieces:int>=0, ability[logic,strategy,memory,negotiation,acting,observation], personality, goal, cooldowns.
- Relation[from][to]: affection[-100,100], trust/caution/debt/hostility/threat[0,100]。方向別。初期 affection=0, trust=40, caution=30, debt=0, hostility=0, threat=30。初対面の数値にシード付き±5（debt/hostility除く）。
- Fact: id, kind, payload, occurredAt, visibility, witnessIds。権威あるゲーム状態のみ生成。
- Belief: holderId, claimId, subject, predicate, value, sourceId, provenanceRoot, learnedAt, confidence, evidenceRefs。真偽は含めない。矛盾する信念も別々に保持。
- Offer: id, proposer, recipient, type, matchId?, round?, targetId?, actionPredicate?, infoClaimId?, payer, payee, amount, timing, expiry, state。
- Promise: id, parties, clauses[], visibility, createdAt, deadline, status, observations, paymentIds。
- Event: id, time, kind, actorIds, audience, references。二重適用不可。ゲーム状態と演出から分離。
- 保存対象: 上記＋NPCの予定/目的/移動中パス、会話使用履歴、乱数状態、保留提案、支払履歴、認識済イベント。プロファイルのバージョンを保存。
## 自由行動スケジューラ
既存タイマーに連動するシミュレーションtick=1秒、意思決定は3秒ごと（暫定）。描画FPS非依存、同時刻の順序は公平なシード付きローテーション。候補：移動、挨拶、交渉、情報交換、密談、探索、サブゲーム、裏ゲーム、休息。対象のアクセス、時間、合法性、在室、活動中、競技の交渉窓をまずチェック。移動はマップの衝突と棟制限を守る。予約中/会話中のNPCへ別交渉を二重開始しない。NPC同士は実際に移動して会う。目撃できる位置なら主人公にも会話中などの表示。詳細は盗み聞き成立時のみ。
候補の効用=0.38*生存期待改善 +0.22*将来の競技優位 +0.13*ピース価値 +0.12*関係価値 +0.10*個人目標 +0.05*探索価値 -0.22*危険 -0.10*時間費用。各項は0〜100の尺度（改善・価値は負値可、危険・費用0〜100）、待機=0。性格重みを各項へ掛け、最大効用付近から難易度別に選択。利益は自分の観測情報から推定。実際の未来結果を使わない。競技中は固有AIが合法手の期待得点・安全順位を比較し、約束/交渉はその評価に加算。違法手・非公開情報アクセスは禁止。
行動時間の目安: 挨拶3秒、交渉ラウンド8秒、密談12秒、調査6秒。NPCの行動時間のみの目安でありプレイヤーUIへ固定待ち時間を課さない。提案受信→返答を最大2秒程度で表示。移動・会話中の自由時間は進む。ポーズ/手帳/強制説明/バックグラウンド中は全員の時計とAI停止。残時間終了時は未成立オファーを取消、成立済み取引は巻戻さない。
探索/サブゲーム/裏ゲームのNPC処理は合法手による実行（競技固有エンジン）、完了時間と立入条件を守る。乱数のみで勝敗を決めない。ストーリー必須の手掛かりは独占による進行不能を防ぎ、記録等の代替経路を残す。
## 交渉種類と入力
ALLIANCE（相互協力、指定試合または日）、NON_AGGRESSION（対象と期限の指定）、PLAN（競技内の行動・対象・ラウンド）、BUY_INFO/SELL_INFO（相手と情報カテゴリ、具体claimId）、RECRUIT（既存同盟から引抜き）、GIFT（無条件譲渡）、LOAN（返済日・額）、REPORT（証拠/噂の提示）、REQUEST_HELP（共同探索や作戦相談）。
自由文で自動判定しない。画面は種類→対象→条件→ピース0〜残高→前払い/成功報酬→確認。互いの支払者を明示。成功報酬は契約時には引落さない。部分先払いはオプションで、前払い額+後払い額が提示総額と一致するよう2条項化。前払いした報酬は自動返金しない。後払いも実際の手続きが必要、破る選択可。GIFTは即時移転だけ。LOANは正の整数・返済期日を持ち、強制徴収なし。返済額上限は元本（利息なし、暫定）。全タイプで無制限債務による経済破壊を防ぐため、未払い総額は新規契約時の支払者所持数以下（実行時は残高再検査）。
情報購入時は知っているclaimIdだけ売却可。本人が持つ事実/噂/意図的な虚偽の主張を選択可能。嘘を販売する場合は実際の情報とは異なるclaimを作成し出所のない証拠は生成しない。購入者に真偽フラグを表示しない。「確かな情報」という口頭主張も真偽を保証しない。未所持の証拠アイテムを売れない。
交渉窓は自由行動または競技が許可するタイミングのみ。競技中に許可されない秘密情報を譲渡できない。M11では補助・ピース交渉不可。正式契約による強制行動は採用しない。
## 価格・成立ロジック
プロフィールのbasePricesを用途ごとの基準要求額にする（-1は固定価格なし、合理性などで判断）。価格は固定閾値でなく、関係と危険で変動。通常の基準額b>=0に対し、
```
need = clamp(b + ceil((caution-trust)/35) + ceil(hostility/50)
             + scarcity + riskPremium - trustDiscount - debtDiscount - mutualBenefit, 0, 12)
scarcity = 1 if ownPieces<=1 and greed>=60 else 0
riskPremium = floor(riskEstimate/35)  # 0..2
trustDiscount = 1 if trust>=70 else 0
debtDiscount = 1 if debt>=40 else 0
mutualBenefit = floor(benefitEstimate/35) # 0..2
```
ceil(hostility/50) は最大2。初期関係・基準bは設定で再調整。estimateは受領側の知識で評価する。取引が受け手からの支払いを求める場合は、買い手の評価額と残高に照らして判断。金額の表示はNPCの要求や対案で行い内部needは表示しない。
以下のハード拒否条件を価格評価より先に処理する。
- 橘: 信頼>=65の既存仲間を意図的に不利にする引抜き・虚偽告発・裏切り依頼は金額に関係なく拒否。道徳条件は本人の信念による。
- 神崎: 作戦が合法でも生存/得点期待改善が0以下なら、単なるピースだけの危険な協力依頼は拒否。情報販売は別判断。
- 黒瀬: 期限/対象/条件が定義されていない成功報酬は具体化を求める。既存の強い約束と衝突する場合は原則拒否。
- 堂島: 根拠のない虚偽告発依頼は拒否。根拠のない噂を事実扱いしない。
- 桐生: 明確な八百長依頼（自分の不利のみを要求）は拒否。競技内の合理的な共闘は可。
- 共通: 非合法/残高不足/期限切れ/到達不能/脱落者/同じ情報の重複売買は拒否。
need以上でも、利益の見込み・リスク・約束整合性を評価。期待効用がマイナスなら拒否。範囲内なら対案（価格・期間・対象のいずれか1要素を変更）。同じ提案への対案は最大2往復、同条件拒否の再提示は30秒クールダウン、条件の実質変更なら再提案可。好感度連打防止のため反復挨拶の関係加算は1日1人1回。贈与の信頼加算上限を1日+6にし、取引の関係変動は固有イベントIDで一度のみ。
## 約束の履行と裏切り
状態: proposed→accepted/rejected/expired; accepted→active→fulfilled/breached/void。複数条項は別々に状態を持つ。合法な行動が存在しない/競技終了で機会消滅はvoid（故意の回避が観測できる場合は別判定）。自発的な違反を強制しない。約束を満たす手の候補集合をアダプターで列挙し、固有AIで評価。約束の内容はラウンド/対象/合法predicateで明確化。「勝たせる」など本人が制御不能な結果を履行保証として使わない。
意思決定時: delta=最良違反手の期待効用−最良履行手の期待効用（共通尺度0..100に正規化）。違反コスト=0.28*loyalty+0.18*morality+0.15*trust+0.08*debt+0.12*predictedDetection*reputationWeight（predictedDetection 0..100、reputationWeight 0..1）−0.12*survivalRisk−0.08*ambition。合理的な代案がある時 delta>cost なら裏切りを検討。履行優先のハード拒否は合意の段階で適用し、橘の強い仲間への故意裏切りも抑止。ただし合法な履行手がない場合はvoid。乱数は僅差の選択のみ（±3）。急な得点差、相手の行動、新しいオファーで再評価。前払いを受けても強制履行しない。相手もプレイヤー同様に履行/不履行の責任を負う。
## 関係更新（観測者→行為者、暫定）
|イベント|好感|信頼|警戒|恩義|敵対|
|---|---:|---:|---:|---:|---:|
|初回有意な会話|+2|+1|0|0|0|
|有償取引の正常完了|+1|+3|-2|0|0|
|協力約束の履行|+3|+8|-5|+3|0|
|危機で無償支援|+6|+8|-5|+12|0|
|無条件贈与（正の額）|+2|+min(amount,3)|0|+min(2*amount,10)|0|
|故意の裏切りを直接確認|-10|-25|+20|0|+18|
|嘘と確認|-6|-15|+12|0|+8|
|後払い不履行確認|-8|-20|+15|0|+12|
|通常の交渉拒否|0|0|0|0|0|
各値clamp。噂だけなら確認済みイベントの変化を確度に応じて最大40%適用、後日確認したら残差適用、誤報と判明すれば該当イベント由来の変更を取り消し再評価（他イベントを巻き戻さない）。脅威=公開順位・ピース・本人が把握した同盟から推定。ピースだけで敵対しない。日末に未接触者への警戒・敵対を最大2だけ初期方向に緩和、重大裏切りのログは維持。
## 情報伝播と秘密
事実ログから知識へのコピーは、公開・当事者・実際の目撃・共有イベントのみに限定。直接証拠100、直接目撃90、口頭初期確度=clamp(20+0.6*trust-0.3*caution,10,80)。演技力は口頭の信憑性を最大±8動かせるだけで、証拠や実際の情報を生成しない。再伝聞は元確度×0.75を上限。情報源の同一provenanceRootを独立証言として二重加算しない。矛盾したら両主張を記録し観測可能な証拠で更新。情報の売却/共有は別イベント。秘密裏に起きた裏切りは、当事者以外の関係数値を即更新しない。手帳に「本人の証言」「他者からの噂」「確認済み証拠」を表示、内部確度数値は非公開。
人物の秘密はプロフィールのsecretDay以降、信頼>=secretTrustかつ対応する手掛かりフラグ（既存ストーリーに接続）を条件として告白候補を解放。告白は選択式。脱落者の秘密は対応日以降に記録/資料から回収できる。秘密告白だけで真相確定にせず証拠との照合を維持。会話ファイルのsecretは未解放なら候補に入れない。秘密のUI一覧や検索に未開示データを渡さない。
## UI/演出
話しかける→通常会話/作戦/情報/取引/同盟/告発/終了。提示内容を確認して送信。返答は受諾・対案・拒否・条件具体化。残時間、双方ピース（公開済み）、支払タイミング、期限、保証されない約束である旨を表示。生存・得点・順位に直接購入効果を作らない。NPCの台詞は判断結果に対応するキーのみ選ぶ。裏切り発覚台詞は知識更新後に出す。秘密台詞・内心・信頼数値・裏切り予定を通常UIから隠す。表情差分のキーは既存アセット定義へ対応、嘘と固定表情を結び付けない。行動確認時のフォールバックを用意。台詞の選択は各NPC/場面で最近3件を避ける（候補不足なら利用可能なものを回す）。変数はプレイヤー入力のエスケープを行う。プレイヤー名のハードコードなし。
## 難易度
EASY: 近い候補少数・限定的な先読み・情報評価誤差大、NORMAL: 標準、HARD: 候補探索/交渉/先読み強化、EXPERT: 制限内の最大探索。どの難易度でも秘匿情報を渡さない。探索計算量に上限を設定して端末での時間停止やフリーズを防ぐ。
