# FALSE CROWN v09 収益化・多言語対応仕様

ZIP はなく、2026-11-27 のユーザーの指示（メッセージ）を v09 として保存したもの。

## 確定仕様（ユーザーの要約）

- 初日無料＋2日目以降は本編買い切り
- 販売価格は未確定
- 広告、ガチャ、月額課金なし
- GitHub Pages 開発版は全日程無料
- iOS 製品版では StoreKit による非消費型アプリ内購入を採用予定
- 初版は日本語・英語の2言語対応
- 日本語版の完成を優先
- 言語別 JSON で文章を管理

## 収益化（元の指示）

- 初日は制限なくプレイ可能
- 初日の終了後、生存者に完全版購入画面を表示
- 購入後はセーブデータを維持したまま2日目から再開
- タイトル画面にも完全版購入と購入復元を配置
- 無料版でも主人公への勝利補正は禁止
- 広告、ガチャ、スタミナ、ピースの現金販売、月額課金は実装しない
- 将来の iOS 版では StoreKit による非消費型アプリ内購入を採用
- GitHub Pages の開発版は全日程を無料解放
- 開発版と製品版の購入判定を分離
- 販売価格は未確定
- 現段階では実際の決済を実装せず、コンテンツ解放の基盤を構築する

## 多言語対応（元の指示）

- 初版対応言語：日本語、英語
- ゲーム内の文章をプログラムから分離し、言語別 JSON ファイルで管理する
- タイトル画面および設定画面から言語を変更可能にする
- 言語変更後もセーブデータを維持する
- NPC の会話、交渉、ストーリー、全35競技のルール、アイテム、実績など、すべてを翻訳対象とする
- 英語の文章量に対応できる可変レイアウトを採用する
- 画像への文字の直接描画はタイトルロゴなどを除き極力避ける
- 将来的に韓国語、中国語などを追加できる構造にする
- まずは日本語版の完成を優先。英語への正式翻訳は日本語の仕様確定後に行う

## 開発の進め方（同日の指示）

- 一定の機能が完成するたびに GitHub へコミットし、GitHub Pages に反映する
- 完成機能と未完成機能を一覧管理する（docs/status.md）
- 受領した v01〜v09 の仕様反映状況、正式素材の組み込み状況を記録する
- 開発版にバージョン番号を表示する
- 全35競技を個別に試遊できる開発者用テストメニュー、任意の日程・施設・イベントから開始できるテスト機能を用意する
- 主人公の敗北、脱落、優勝、真相ルートを検証する
- 開発者用機能は製品版から除外する
