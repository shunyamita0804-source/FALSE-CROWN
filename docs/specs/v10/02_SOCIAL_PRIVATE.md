# NPC交流・個室密談
公の場の主メニュー：雑談／情報交換／取引／同盟を提案／密談に誘う／何でもない。個室の主メニュー：雑談／情報交換／取引／同盟を提案／密談（秘密情報、秘密作戦、他者の動向、個人的な話のサブメニュー）／終了。個室でも第三者が同席すればその人に聞こえる。公開取引と秘密取引の違いは知識の可視性。既存v03の契約/支払い/合法性を再利用。
同行：相手が承諾した場合だけ追従状態、主人公の過去経路または経路探索で後ろを歩く。瞬間移動や重なりを避け、扉・階段・棟制限に従う。個室への入室は招待・在室者同意が必要。他NPCの個室へ無断侵入不可。NPCからの誘い、NPC同士の誘いも同ルール。複数人会議は個別同意と定員（初期4人）を必要とする。拒否/途中退出/締切/脱落/到達不能で終了。同行中も時計進行。NPCの判断は予定、信頼、危険、期待利益。主人公専用優遇なし。
秘密情報：次の競技の購入可能なヒント、探索済み入口、裏ゲーム存在、他者の同盟/取引/作戦、観測した弱点。NPCは実際にピースを支払い情報を買う/探索する/目撃する/伝聞する。取得済みclaimだけ共有可能、未取得なら知らないと答える。無償共有、価格提示、拒否、虚偽主張があり得る。物証を捏造しない。ストーリー告白は既存解放条件を維持。NPCに先取りされてもプレイヤーの原本は消さない。公開情報は公の場でも交換可能、秘密情報の具体的内容の交渉は私的な場所に限定。
秘密作戦：対象人物、対象競技/ラウンド、合法行動、期限、ピース報酬、前払い/成功後を構造化。偽装同盟→合法な裏切り、対象の攻撃/優遇、情報収集、同盟秘匿、虚偽情報の流布。競技に存在しない行動は選択不可。例：神崎に御堂との偽装同盟を提案しM01の指定ラウンドで協力しないよう依頼。NPCは別途相手に提案し、成立しない場合は条件不成立。本人が制御できる行動を約束し勝利を保証しない。受諾・対案・拒否・再評価・不履行をv03に従って処理。M11の補助交渉禁止は維持。競技アダプタごとに許可コマンドを定義、全35競技へ一律の裏切り操作を強制しない。
目撃：同室・視線・距離・遮蔽物により同行/入室/公開交渉を観測。入室目撃は同盟の推測のみで密談内容は不明。公開交渉の詳細は近距離で聞こえた内容のみ。盗み聞きは扉付近など明示した条件で成立し、断片しか得られない場合あり。監視の全知化禁止。噂はv03の出所・確度・伝播を再利用。競技行動による推測と確認済み事実を分離。目撃だけで必ず敵対させず、性格・既知の関係・利益によって警戒/脅威/信用を更新。競技中の指摘・交渉・合法手の評価へ反映。誤報訂正、重複イベント防止、秘密が漏れないケースをテスト。
関係一覧：全参加者の顔、名前、公開ピース、生存状況、主人公との推定好感度（段階またはゲージ）、本人が知る同盟/約束/貸借、噂と事実の区別。v03の方向別6値を維持、真の信頼・敵対・裏切り意図は非公開。推定値は観測した会話・行動だけで更新。未接触は不明表示、脱落者は状態のみ残す。
