# 検収・テスト
- 時計：FPS差、ポーズ/復帰、日跨ぎ、時刻ジャンプ、12/18/22時の強制遷移、DAY11、会話中締切、セーブ再開、二重報酬なし。
- 生活：全生存者の朝夕食・入浴・帰室、脱落者除外、監獄中の立入制限、帰還後合流、家具/導線、PC/iPhone。食事やシャワー素材が不足する場合は仮演出と不足一覧を残す。
- 同行：拒否、追従、階段、部屋の許可、複数人、途中離脱、NPC同士、締切、セーブ復帰。タップ移動禁止は維持。
- 情報：NPCの実取得、支払い、秘密の保持、目撃と伝聞、虚偽、誤報訂正、未取得情報がAI/UIに漏れない。密談の有無で同一条件を比較。
- 作戦：合法/違法、受諾/拒否/不履行、前払/後払、対象脱落、競技ごとの対応表、全競技の回帰、主人公への勝敗補正なし。
- 探索：H02変更、H01〜H08の到達可能性、全勝・0ピース・全告白拒否でも代替経路を実測。自由時間の不足時は倍率/経路を調整。時間制変更による進行不能を許容しない。
- 音：タイトル/廊下/個室、連続移動、フェード、音量、iOS再生。実機確認できない場合は明記。
- 進捗表とテスト結果を更新、正式素材と仮素材を区別、コミット・GitHub Pages反映。製品版に開発者メニューを含めない。
