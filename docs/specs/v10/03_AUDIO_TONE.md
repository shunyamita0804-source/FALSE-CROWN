# 音楽・世界観
タイトルをShiny Tech、居住区廊下をAirport Loungeへ差替。添付MP3は原本。個室専用曲は未決定、暫定的に静かな既存ラウンジ曲または無音で運用し、最初の部屋で旧ミステリー曲を再生しない。食堂/ラウンジは既存曲のうち非不穏なものを暫定利用。他のBGMは別途見直し。密談で自動的に不穏な音に切り替えない。同曲間は再生維持、別曲はフェード。iOSの初回操作で音声解禁、復帰時の重複再生防止。圧縮やループ加工はクレジットに記録、旧曲は必要に応じ残すが旧タイトル/廊下への割当解除。

世界観は高級な閉鎖型頭脳戦大会。序盤の殺人推理・過剰な伏線・オペラ/ゴシック演出を抑える。NPCの普通の雑談、食事、勝負への意気込みを増やす。真相は自主探索でのみ徐々に開く。脱落は大会敗退。通常優勝だけでも完結する。隠しストーリーの構造とエンド条件は維持し、早期ネタバレを避ける。
