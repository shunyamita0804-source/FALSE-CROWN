# ゲーム全体仕様
## 確定事項
FALSE CROWN（仮称）。1人用、主人公1＋固定NPC11。男女主人公、名前選択。現代の閉鎖施設で頭脳戦・心理戦・探索。横画面、PC/iPhone。NPCは自律し、ピースで交渉・情報購入・裏ゲームを楽しむ。ピース0で脱落しない。強制同盟、直接得点購入、脱落免除は禁止。メインマッチの順位だけで棟分け、監獄マッチ最下位だけが脱落（決勝は敗者が脱落）。毎日1人、11日目は2人の決勝。全競技の実プレイが必要。物語の脱出等は任意の別エンド。通常大会を途中で強制終了させない。

## 日程と時間
DAY01〜10の開始人数/監獄人数：12/4,11/4,10/4,9/3,8/3,7/3,6/3,5/2,4/2,3/2。残りは生活棟。DAY11は2人で決勝。朝自由行動→ルール説明→作戦会議→メイン→報酬・棟分け→棟別探索→監獄マッチ→脱落→深夜自由行動→翌朝合流。生活棟側の監獄試合はCPUで実行し結果発表（観戦は任意、未公開手札は見せない）。メインマッチ終了時に生存者全員の同点を解消して順位確定。脱落者の競技参加・取引・移動を停止、隔離ルートの物語登場のみ可。
暫定リアルタイム：朝5分、作戦会議3分、生活棟7分、監獄棟5分、深夜3分。競技の交渉時間は各ルールによる。ポーズ、手帳、強制ストーリー、ルール説明、バックグラウンド時は停止。通常会話・交渉・移動中は進む。タイムアウトで取引未確定なら取り消し、競技開始へ安全遷移。裏ゲームは入場前に残時間確認、開始後は独自タイマーに切替、終了後に消費時間反映（暫定：残り時間超過で自由行動終了）。

## NPC自律・交渉
各NPCは他者ごとの好感(-100〜100)、信頼、警戒、恩義、敵対、脅威(0〜100)を保持。別に強欲、忠誠、野心、道徳、リスク、探索意欲を持つ。方向付きの関係（A→BとB→Aは別）。内部数値非公開。初期値・重みは暫定設定。定期tickで合法行動から期待利益、リスク、人格、信頼、約束、順位、残時間を評価し選択。施設の立入制限を守り経路探索。会話/取引/探索/協力/妨害/休息を自律実行。能力差は合法候補の探索深さ、記憶、推論、誤差で表現。プレイヤーだけを狙う・救う補正は禁止。NPCは自分の手札、自分が観測した情報、公開情報のみ取得。秘密状態をAIに渡さない。
会話UI：挨拶、情報交換/販売、同盟、不可侵、作戦提示、引抜き、告発、貸借/贈与、取引拒否/対案。条件は相手・対象行動・対象試合/期間・支払い数/時期・共有情報ID。期限と観測可能な履行条件を持つ。口約束は破れる。NPCごとの最低条件と拒否条件を作る（橘は仲間への裏切りを高額でも拒否することがある、神崎は戦略上の合理性を要求、御堂は利益重視）。受諾後も勝敗期待や危険が変われば再評価して裏切り可能。取引は履歴保存。
事実ログと各NPCの信念を分離。情報ID、内容、取得元、日時、目撃者、共有経路、確度、真偽（内部のみ）。裏切りの評価は本人が観測/伝聞した時だけ更新。虚偽情報も流通。手帳はプレイヤーが得た事実/噂/約束/順位/資産/探索/所持品を表示。未発見の正解やNPC内心を表示しない。難易度4段階は探索深さ等を変え、隠し情報を解禁しない。外部AI/API不要。
