# 技術・素材・検収
## 技術構造
既存技術を調査し再利用、不要な全面書換え禁止。TypeScript等で型付き状態を推奨。ブラウザ完結、外部AI/API・常時サーバ不要。GitHub Pagesのサブパスで全URL/アセット解決可能、更新/直リンクで破綻しない。将来iOS用にWebView等へ移植できるようプラットフォーム固有処理を境界化（方式は既存構成と検証で決定、App Store承認は保証しない）。ビルド依存を固定、オフラインは初回取得後に動作可能としキャッシュ更新を検証。
論理と描画の分離：core（大会状態機械/経済/時間）、npc（認識・行動・関係・交渉）、matches（m01〜m11,p01〜p10,h01〜h08,s01〜s06）、world（マップ・衝突・探索）、story（条件・台詞・エンド）、ui（表示と入力）、assets（登録）、save（保存・復元）。各競技は初期化/合法手/入力検証/遷移/参加者別ビュー/結果/シリアライズ/AIを持つ。NPCに全状態を渡さない。シード付き乱数、描画FPSと無関係のシミュレーション時間、再現ログ。競技内のCPU同士も同じルールエンジンを使用。UI操作から不正な遷移をできない設計。
セーブ：バージョン付き、主セーブ＋直前バックアップ、進行・時間残・NPC関係/記憶/約束/ピース・競技状態・手札・乱数・イベント/取得済報酬・解放済要素を保存。フェーズ遷移、取引、競技手確定、アプリ中断で自動保存。再開で報酬二重取り・時計巻戻し防止。データ破損時はバックアップ。ローカル保存が消える可能性に備えエクスポート/インポート（検証付き）を用意。周回図鑑は別データ。オフライン・アプリ中断復帰テスト。

## 描画・素材差し替え（最新指示）
GBA遊戯王7/8は人物の頭身・シルエット・相対サイズ・視点・4方向移動のみ。全画面低解像度、粗い文字、拡大ドットフィルタ禁止。現代的な高精細2D、黒/濃紺/金/象牙/深紅、上品な光影。論理画面1280×720、実描画はDPRと画面サイズに適応。UI・文字は高解像度レイヤー（DOM/CSS等も可）、タッチ領域とセーフエリア確保、画面の比率差はレイアウトで吸収。場面ごとの滑らかな遷移。仮素材でもUIの可読性を確保。キャラのみ低解像度拡大という方式も正式版に固定しない。
- キャラ 1コマ96×128px、walk 384×512（4列×4行：下、上、左、右）、stand 384×128（下、上、左、右）。セル内足基準48,120を目安に透明余白確保、正式素材で微調整。立ち絵768×1024、顔256×256、旧名維持。
- タイル64×64px（旧16×16の4倍）。16列16行シートなら1024×1024。マップ/オーバーレイ/家具の旧ピクセル寸法を4倍、タイル数、入口、衝突、人物との相対サイズは維持。ストーリー背景2560×1440は変更しない。旧manifestは参照用。正式納品時の寸法や前景差分を確認。単純拡大ではなく高精細描き直しが必要。
- UIは旧manifestのサイズを基本とし、文字/数値/カード値/盤面/入力はプログラム描画。素材を一枚絵に焼き込まない。9-slice用余白は実素材で確認。画面見本は実装用部品にしない。
- assets registryで論理ID→パス/シート分割/アンカー/スケール/前景/9-sliceを設定。素材欠落時は仮素材を表示し開発続行。素材差し替えでゲーム状態、衝突、ルールが変わらないこと。素材の動線や家具位置が仮設計と異なる場合はマップ定義を意図的に修正して検証する。各担当の新manifestを統合し旧寸法を上書きする。
- 画面：タイトル、主人公選択、フィールド、会話、交渉、手帳、地図、所持品、交換所、掲示板、ルール/練習、全35競技、結果、脱落、決勝、8エンド、ギャラリー、フリー対戦、設定。PCはキーボード、スマホは仮想十字キー/タップ移動、調べる。文字拡大、音量、ポーズ。色だけで区別しない。
- サウンドは仮音/無音でも進行可能。正式BGM/SE後付け、商用利用可ライセンス・出典・クレジット記録。会話/競技/環境の切替、音量設定を独立。

## 検収項目
1. 12人→2人→1人。毎日監獄下位1人のみ脱落、ピース0は生存、上位は監獄に送られない。脱落NPCは通常競技に復帰しない。
2. ゲーム全35種をプレイヤーが操作してクリア/敗北可能、フリー対戦でも同じルール。決勝5種。全競技の合法手、同点、時間切れ、残資源0、空入力、終局、NPCのみ試合をテスト。
3. NPCの観測外情報参照禁止をテスト。NPC同士の取引、約束、裏切り、情報共有、棟制限が実際に起こる。買収拒否が可能。残高保存・二重取り防止。
4. 探索：入口出口、家具の衝突、ワープ、秘密条件、開錠差分、報酬一度、早期NPC脱落で詰まらない、8エンドの到達性。
5. 保存・再開：各フェーズ、競技途中、裏ゲーム、交渉、バックグラウンド、オフライン。タイマー停止と復帰が正確。キャッシュのバージョン更新。
6. PCとiPhone横画面、読みやすい文字、操作範囲、表示切れなし、画面回転、欠落アセット時も進行。iPhone実機が無い場合は未検証と明記。
7. 自動対戦で各ゲーム複数シード、席/役職別勝率、同点率、支配戦略、試合時間、NPC強度を記録。単体/統合/通しテストを保存。仮素材でも初日〜決勝までプレイ可能なことを実証。
8. リリース段階の品質判定：全ゲーム、全画面、全必須データ、各エンド、素材整合、エラーなし、ライセンス、iOS実機・審査向け要件は別途確認。仮実装は正式完成と呼ばない。
