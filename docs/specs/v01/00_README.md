# FALSE CROWN — CC 開発指示パック v0.1
既存 false-crown リポジトリに統合する。新規リポジトリは作らない。現状を確認してから変更し、既存の Pages 公開を維持すること。これはゲーム全体の設計・実装指示であり完成素材ではない。

## 作業順
1. 既存コード、ビルド、Pages、操作系を確認。仕様を docs/ に保存し実装チェックリストを作成。
2. 状態管理・セーブ・素材レジストリ・画面ルーティング・施設移動を実装。
3. DAY01（探索、交渉、M01、棟分け、P01、脱落、DAY02への遷移）を仮素材で実際に遊べる状態にする。
4. NPC自律行動、情報伝播、全日程と全競技を順次実装。各競技は独立テストを作る。
5. 隠し探索、ストーリー、エンディング、フリー対戦を実装。全日程の通しテストを実施。
6. 素材担当から正式PNGが届くたびに素材レジストリで差し替え、描画・座標を検収。機能を削除しない。
7. Pagesに公開、PC/iPhone横画面で検証。将来のiOS化に備える。

## 優先順位
ユーザー確定事項 > 本パックの明示した暫定値 > 旧デザインZIPの旧解像度 > CC独自判断。矛盾・未確定値は docs/decisions.md に記録。勝敗・脱落・物語の重大な変更は勝手に確定しない。細部の暫定実装で進行を止めず、設定で変更可能にする。
