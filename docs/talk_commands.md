# 生活・競技のコマンド 動作表（現行 main、v0.29.3）

- 作成：2026-11-28。v0.29.2 の main を調べ、この版（v0.29.3）で直した点を反映した。
- 「状態」の列：**済**＝実装済みで動く、**今回**＝この版で直した・足した、**未**＝未実装（画面に出さない、または出ても中身がない）。
- 判断はすべて主人公と NPC で同じ関数（`npc/negotiation.ts` の `evaluate`、`npc/social.ts` の `inviteVerdict` など）。主人公への補正はない。
- 内部の数値（信頼、好意、警戒、敵意、裏切りの確率）は画面に出さない。画面に出るのは相手の台詞と、手帳の「関係一覧」の推定だけ。
- 時間：会話を開いても大会の時計は止まらない（作戦時間も同じ）。手帳・設定を開いている間だけ全員が止まる。ゲーム内 1 分＝現実の 1 秒。

## 0. どこで何が使えるか（一覧）

会話を開くと、相手の名前の上の欄の先頭に「いまの場所と話の範囲」が出る（今回）。

| 場所・場面 | 欄の表示 | 使えるコマンド | 使えないもの（理由） |
| --- | --- | --- | --- |
| 生活棟の公の場（廊下、ラウンジ、図書室、遊戯室） | 生活棟：人目あり | 雑談／情報交換（最近の様子、告発）／取引（贈与、貸借）／協力の約束（緩い約束、救済の約束）／密談に誘う | 秘密の情報の売買、動向、個人的な話（2 人きりの時だけ） |
| 共用の場（食堂、大浴場、中央ホールなど） | 共用：人目あり | 生活棟の公の場と同じ | 同上 |
| 自分の個室・相手の個室で 2 人きり | 個室：2 人きり | 雑談／情報交換（秘密の売買も）／取引／協力の約束／密談（秘密の情報の売買、動向、個人的な話）／相談を終えて解散する（招いた相手がいる時） | 第三者が 1 人でもいれば公の場と同じ |
| 監獄棟（房、共同牢、監獄の共用） | 監獄棟：人目あり、密談不可 | 生活棟の公の場と同じ。ただし密談に誘うと「房は格子越しに丸見えで 2 人きりになれない」と出る（今回。以前は「定員は 4 人」と誤った理由が出ていた） | 密談、個室への招待（招く先がない） |
| 作戦時間（M01 のルール説明の後。大会競技場） | 作戦時間：競技の相談 | 協力を持ちかける／相談室で話そう／情報を交換する／コツを聞く／コツを教える／約束を確かめる／相談室（入口を調べる） | 会場の外へは出られない（全員同じ） |
| 競技中：ラウンドの間も相談できる競技 | ラウンドの間だけ相談可 | 休憩・交渉の段階で：同盟／不可侵／ピースを渡す（M01 だけは作戦時間と同じ新しいメニュー） | 作戦の約束、次の手を聞く（v11 の競技に部品がないので出さない。今回） |
| 競技中：手番の待ちも相談できる競技（M04、M06、M09、P05） | 相手の手番の間も相談可 | 上と同じ。**自分の手番の間は話せない**（今回） | 同上 |
| 競技中：相談できない競技（M11、P01〜P04、P06、P08、P09） | 相談不可（雑談のみ） | 雑談だけ（今回。以前は同盟や贈与まで出ていた） | 協力、取引、情報 |

競技ごとの区分は `src/data/match_talk.json` の `window`（`docs/venue_talk.md` の 2 章の表）。

| 区分 | 競技 |

**相談室の退出の決まり（今回、`core/strategy.ts` の `leaveMeeting`）**
- 成立した約束（協力、緩い約束、救済の約束）は、退出しても、枠が終わっても取り消さない。
- 出た人は、その枠の会議から外れ、予約（その枠の相談の予定）も解ける。同じ枠のうちは同じ部屋へ戻れ、ほかの相談にも加われる。
- 残った人が 2 人以上なら、その人たちだけで相談を続け、枠の終わりに NPC 同士の判断で解決する。主人公が部屋の主だった時は、残った人が主になる。
- 1 人しか残らない時は会議を解散し、その人の予約も解く（呼ばれて歩いている途中の人も同じ）。
- ほかの部屋へ入る、別の人の相談に加わる時は、前の相談から自動で抜ける（1 枠に 1 人が入る相談は 1 つ）。
- 枠の時間切れ：まだ決めていない話は取り消し、成立した約束は残す。開いていた会話や相談室の画面は閉じる。

## 4. 期限・終わり方のまとめ

| 記録 | どこで終わるか | 約束破りになるか |
| --- | --- | --- |
| 緩い約束 | 同じ競技に出た後（使い終えた）、期限（2 日後）を過ぎた時 | ならない |
| 同盟・不可侵・協力 | 期限の日を過ぎた時、どちらかが脱落した時 | 競技の中で約束に反した手を打った時だけ（M02・M03・M05 のように競技が判定できる時） |
| 協力の解消 | 自分から申し出た時（相手に伝わる） | ならない（信頼が少し下がる） |
| 貸借 | 期限の日の終わり（NPC が借り手） | 返さなければ不払い。主人公が借り手の時は返すまで残る |
| 救済の約束 | その日の救いのメダルの後 | 強制はない |
| 招待・同行 | 期限（約 110 秒）、消灯、集合、解散、行けない場所 | 関係なし |
| 作戦時間の相談 | 枠の終わり、退出、準備完了 | 関係なし（成立した約束は残る） |
| 会話の画面 | 自分で閉じる、集合の時刻 | 関係なし（成立した約束は残る） |

## 5. まだないもの（次にやる候補）

- 手続き室（出題室・任務室）での選択と、その前後の会話。
- M01 以外の競技の作戦時間と、競技ごとの協力の中身（約束できる行動、守ったかの判定）。
- 主人公が借りたピースの期限切れの処理。
- 監獄会場の相談席。
