組み込み
charactersを既存の同一パスへ追加してください。portrait_normal.pngは本納品には含めず、採用済みを保持します。
各表情は同じ画像寸法・同じ表示サイズ・同じ原点（アンカー）で切り替えてください。
referencesとcomparisonは確認資料で、通常絵の差し替え対象ではありません。
preview.htmlは4ZIPを同じフォルダに展開後、ブラウザで開くと人物・表情を切り替えて確認できます。
HTMLのマイク通常絵は添付JPEG原本のため背景が白く、7差分は透過です。

検査
77枚のPNG読込、寸法、RGBA、透過、ファイル名、ID、欠品、重複、SHA256、ZIP破損を確認。
通常絵との輪郭重なりと胴体部の推定位置ずれを数値測定し、全員の比較一覧を目視。
顔の二重化、大きな首・肩・頭の位置の変化、明らかな背景残りがないことを確認。
生成画像はピクセル単位で同一の描画ではなく、線・陰影の微細な差があります。
通常絵との胴体部の推定ずれは最大2px（768×1024基準）。数値はqa_numeric.csv。
