# FALSE CROWN 主人公男女・歩行／待機／着席

## 完成素材：6枚
characters/hero_m/ および characters/hero_f/ に各3枚。
- walk@2x.png：768×1024、192×256セル、横4×縦4。上から下・上・左・右向き、各4コマ。
- stand@2x.png：768×256、左から下・上・左・右。
- sit@2x.png：768×256、左から下・上・左・右。椅子・影なし。
全素材は背景透過RGBA PNG。

## デザイン
採用済み通常絵2枚をreferenceに同梱。
男性：黒髪、青灰色の瞳、チャコールジャケット・薄灰色ニット。下半身はチャコールのストレートパンツと黒い革靴。
女性：ダークブロンド、ヘーゼルの瞳、青緑ジャケット・アイボリーブラウス・小さい銀色耳飾り。下半身は紺の足首丈パンツと黒いローファー。
各方向・全素材に共通する服装として制作。

## 配置
立ち・歩き：頭部の中心x=96、頭上端y=16、足元基準y=240。頭部の高さと胴体・脚の配置を補正し、待機と歩行の高さを224pxに統一。
着席：腰・座面接点(96,180)、足元y≈240。横向きは腰位置を軸にして配置するため、頭や足は中心から前後に出る。
描画原点は立ち・歩き(96,240)、着席(96,180)を推奨。ゲーム側の旧位置補正を重ねず、実装時に表示を確認する。

## 検査
6枚の寸法・RGBA透過・セル境界内への収まりをプログラムで検査。全32歩行コマを一覧で目視し、1・3の手足の逆転、2・4の通過姿勢を確認。頭部・人物サイズ・足元を配置補正。
GIFは最終納品PNGから作成。確認用画像とGIFの背景・文字・補助線はゲーム素材には含まれない。
本制作は画像生成を使用。ゲームへの組み込み・iPhone実機での動作検収は未実施。
