# FALSE CROWN NPC11人 歩行修正版 v2（検査用）

characters/<内部ID>/walk@2x.png の11枚を修正しました。768×1024、4×4、192×256セル、RGBA透過。
stand@2x.png と sit@2x.png の計22枚は前回納品とバイト単位で同一です。現状保持のまま同梱しました。

## 修正内容
・全11人×4方向を対象に、1・3コマ目の反対側の脚の踏み出しと腕の振りを再制作。
・2・4コマ目を、支持脚と遊脚が交替する通過姿勢へ修正。
・左右の手足を色分けした検査用生成を経て、正式の服色に復元。
・右向きの腕の重なりと、待機より大きくなった頭部を追加修正。
・方向ごとに修正版を比較して採用し、セルごとに等比縮小と配置を調整。
絵の制作・修正は画像生成で行い、後処理はセル切り出し・等比縮小・配置・シートとアニメーションの組み立てです。

## 確認用アニメーション（別ZIP）
各人物の *_loop.gif：左から下・上・左・右を同時表示、160ms/コマ、1→2→3→4の無限ループ。
各人物の *_idle_walk.gif：待機→歩行1→待機→歩行3、400ms/コマ。
NPC11_all_directions_review.mp4：約49.6秒。11人順、通常ループ3回、低速1回、待機切替。
review.html：納品PNGを埋め込んだオフライン確認用。再生/停止/コマ送り/待機切替/速度切替。
全アニメーションは今回の最終PNGから作成し、フレーム順序・フレーム数・時間・動画のデコードを検査しました。
全44方向について比較画像の待機・1・2・3・4を目視で比較しました。ライブプレーヤーによる全ループの再生目視検査は完了していません。

## 実測結果
歩行176コマ：全高224px、上端y=16、足元の可視境界y=240。
上部シルエット中心x=96に対する誤差は最大0.5px。セル端切れなし。
同じ方向の4コマ内の頭部領域の幅差は最大2px。
ただし待機と歩行の頭部領域の幅差は最大7px残っています。
髪・顔・小物は同じ参照を使用していますが、画素単位で共通の頭部レイヤーを使った素材ではありません。
全高の一致は、顔・髪の形や小物の完全一致、切替時の見た目の変化ゼロの証明ではありません。
全方向で反対側の手足が解剖学的に完全に正しいという最終合格は出していません。特に同色の服で隠れる手前/奥の腕・脚の関係には再確認の余地があります。
よって本ZIPは修正を行った検査用v2であり、すべての採用条件を満たした完全合格版とはしていません。
ゲーム組み込み・iPhone実機の動作・着席と家具の適合は未検証です。
