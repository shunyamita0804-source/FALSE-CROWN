# FALSE CROWN 建物・マップ素材 引き継ぎ

追加指示を優先し、フィールドタイルを64×64px、人物縮尺を96×128pxとした。元のマップ指定タイル数は維持し、マップ・家具・タイルセットの縦横ピクセル数を旧指定の4倍にした。ストーリー背景は2560×1440pxのまま。

画像86点（基本マップ32、解錠差分5、家具34、タイルセット5、背景10）を生成し、寸法とファイル存在を検査した。`manifest.csv`、`validation_report.csv`、`tile_index.csv`、`prop_footprints.csv`、`map_handoff.csv`を参照。

## 実装上の未検証事項

- 基本マップは一枚絵で、家具が画像内に描かれている。独立家具PNGも付属するが、マップ背景から家具を除去した床レイヤーと手前に重なる前景レイヤーへの分離は完了していない。配置時の二重表示を避けるには追加作業が必要。
- タイルセットは64px格子の透過PNGだが、任意のセル組み合わせで全境界が連続するかの実装検証は未実施。`tile_index.csv`の用途分類は暫定。
- 解錠差分は透明キャンバス上に開状態の個別素材を置いたもの。元マップ内の閉状態を完全に消す差分にはなっていない。
- `map_handoff.csv`の出入口座標は画像からの概算。接続先ID、衝突判定、調査座標、NPC経路、隠し通路の実機テストは実装担当との照合が必要。
- 人物は承認時の縮尺見本のみで、本納品86点には正式キャラクター素材を含まない。

各ZIPは30,000,000バイト未満。連番ZIPの中身を同じ相対パスで一つのディレクトリに展開する。画像の重複格納はない。
