# 未接続の出入口の一覧（v0.26.1、2026-11-28）

建物改修の納品にある出入口の候補のうち、今のゲームのどの扉にもつながっていない 26 か所。番号は `exit_candidates.png`（同じフォルダ）の赤い丸の番号と同じ。位置はマス（1 マス 64 ピクセル、左上が 0, 0）。
